- 初始20万元；每笔固定约2万元（含买费、100股整手），盈利不增加单笔金额或20万元未平买入成本上限。现金不足保留未成交。
- 买卖各3bp、零滑点。A—F买入后1个交易日收盘卖；G为2日；H为4日。目标卖出日无有效报价顺延，长期无报价保留待平与报价日期。
- 次日开盘按模块顺序、池内评分分位、评分、代码竞争名额；同日同股去重，已持仓不加仓。
- 这里运行日线信号和模拟账户。完整合格池用于模拟执行，Top4仅是展示，不截断实际执行池。

- U：A、B；
- Q1：G；Q2：D、C；Q3：E、F；Q4：H。只展示当前Q，不展示其他Q。

## 内部定时与失败处理

GitHub `schedule`：北京时间 **17:00主扫描、18:00完整性补跑**，周一至周五；中国A股休市跳过。完成同一日期且参数哈希不变则幂等跳过，模拟账户同日不会重复买卖。GitHub排队可能延迟实际开始时间。

首次冷启动从公开通达信盘后包恢复2023年以来有效记录；随后缓存每股最近140条**有效报价**与完整市场环境序列，增量下载新交易日，避免每天全量重建。B的换手因子使用搜狐历史换手率，并校验同日原始收盘价。

缺日期、指数缺失、市场覆盖不足、低评分覆盖均明确失败/部分完成，失败报告仍保存；不会用昨天数据冒充今天。单个股票字段缺失不影响其他模块，缺失不填零。报告和模拟状态在 `reports/`、`paper/` 持久保存，不依赖ChatGPT临时工作区。

手动运行：Actions → **DCEGHABF daily close scan** → Run workflow。`asof`留空取北京时间当天；历史日期需独立干净缓存，不能用未来滚动缓存回看过去。

