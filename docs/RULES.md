# 完整冻结规则

## 环境

当日收盘后判断：上证000001.SH收盘≥含当日MA20为线上，全A有效报价上涨家数/有效交易家数≥55%为宽度高。平盘计入分母、停牌/零量剔除，含历史ST。Q1线上高，Q2线上低，Q3线下高，Q4线下低；没有MA斜率条件。

所有股票池限沪600/601/603/605、深000/001/002/003，至少60条有效记录，原始收盘≥3元。

## 基础池

1. A/B/C/G：放量突破20日。T收盘≥此前20条有效收盘最高值；T成交量≥此前20条均量1.5倍。两个窗口均排除T。
2. D/H：缩量守位。启动L涨幅>5%，阳线，量/此前20均量≥2，收盘≥此前20收盘高点。后续1—3条有效记录中，每个收盘≥min(启动实体中点,启动前20日收盘高点)，后续均成交额≤启动日65%。
3. E/F：阳线后低开涨停。紧邻前一交易日有有效报价且C>O，T开盘<官方前收，T收盘达到前收×1.10四舍五入至分的近似涨停价。不要求首板或反包。

## 评分和排序

每个因子在**完整当日基础池**按非缺失值均值与总体标准差(ddof=0)标准化；常数截面、所用因子缺失则不评分。只用非零项。分位为平均并列排名百分位；先计算分位，再筛环境/门槛/开盘缺口，不在筛选后重新排名。

固定模块顺序DCEGHABF；模块内按分位降序、评分降序、代码升序。不同公式不直接比较原始分数。同日同股去重，已持有不加仓。只买当天通过开盘缺口的第一只；固定约2万元、100股整手、每日新买最多1只。

## 买卖与资金

单笔股数=floor(20000/(开盘价×1.0003)/100)×100。未平买入成本总和≤200000元。利润留现金，不增大单笔金额或本金上限；现金不足、整手不足保留未成交。开盘买、收盘卖，不能提前使用当天收盘卖出款。A—F买后1个交易日收盘卖；G买后2个交易日收盘卖；H买后4个交易日收盘卖。例：T信号，T+1买，A—F通常T+2卖，G通常T+3卖，H通常T+5卖。目标日无有效报价顺延。买卖各3bp、零滑点。

## 当前环境模块

U始终显示A/B；Q1显示G；Q2显示D/C；Q3显示E/F；Q4显示H。分别显示U合并Top4、当前Q合并Top4、每模块观察Top4和组合优先Top4；观察股标明是否过评分门槛，开盘条件都标记待确认。

## 因子数学定义

# 因子实现约定

先阅读protocol.md。V为股数、A为元，O/H/L/C为同一口径复权价，P为原始收盘，pc为官方前收。r=P/pc−1；prev/lag均按本股票有效记录；std默认样本ddof=1（唯截面z统一ddof=0）。窗口不足不缩短。分母0/非法则NaN。一字板高=低的比例类因子为NaN。

- 量比5/60：V_T/mean(V_{T−n+1:T})，均量含T。
- 反向换手20：tbar=mean(turn20)，单位百分数；按[-inf,1)、[1,3)、[3,7)、[7,inf)分段。每股票每段从2023-01-01以来截至T累计min/max，rev=−(tbar−min)/(max−min+1e−12)。每段分别保留跨时状态，不能整段全期min/max；不能每年重置。仅涉及该因子策略加旧锚点2025-05-06兼容复核。
- 开盘强度：原始开盘/pc−1。
- 连板：截至T连续有效报价收盘涨停数，未涨停清零；缺限价则未知，不能强判。
- 均线价格位置：0.4×I(MA5>MA10>MA20)+0.6×C/max(H最近120记录)，MA含T。
- 振幅：(H−L)/C×P/pc。等比例复权下等于原始(H−L)/pc。
- 估算流通市值：P×V/(turn/100)。turn=V/同日可流通A股数×100；故本代理可能与真实流通市值高度相关，不能当独立证据。
- 收盘位置：(C−L)/(H−L)。上影比例：(H−max(O,C))/(H−L)。
- VWAP乖离：P/(A/V)−1；A/V为全日成交均价的日线代理，不是分钟VWAP重建。
- 5日动量：C/lag(C,5)−1。
- 20日相对动量：C/lag(C,20)−1减当日有报价主板行情全集该值的中位数，不在信号池算中位数。
- 波动压缩：std(r最近5)/std(r最近20)，样本标准差。
- 量能加速度：mean(V最近3)/lag(mean(V最近10),3)。分母截至T−3的10记录均量。
- 量价效率：(C/lag(C,5)−1)/sum(abs(r)最近5)。
- OBV斜率：(OBV_T−OBV_{T−5})/sum(V最近5)，OBV累加sign(r)×V，平盘贡献0，差分只依赖近5。
- 逆市强度：r×(1−B_main)，B_main与环境B_all不同。
- 突破幅度20：C/此前20记录最高C−1。
- 启动后缩量比：启动L为r_L>5%、V_L/此前20记录均量≥2、C_L>O_L、C_L≥此前20最高C。对k=1、2、3，要求L为T之前第k有效记录、L后至T各收盘≥min((C_L+O_L)/2,启动前20最高C)；顺序找第一个成立k，取该k记录均A/A_L。因子本身不要求比≤0.65，只有pool5信号要求该阈值。
- 龙虎榜净买占比/成交占比/流通市值/净买额/买入额/卖出额：去重后的DEAL_NET_RATIO、DEAL_AMOUNT_RATIO、FREE_MARKET_CAP、BILLBOARD_NET_AMT、BILLBOARD_BUY_AMT、BILLBOARD_SELL_AMT。金额人民币元，比例记录源百分数单位并统一；无记录NaN，不是0。不能用买卖额自己构造一个不同分母替代源净买占比。历史单日榜优先，仅同日合格单日记录中买入额最大；多日榜无法分拆则不当单日；买入额并列按TRADE_ID升序再按原始记录规范JSON升序稳定去重。
- 总市值：历史同日TOTAL_MARKET_CAP，真实流通市值：NOTLIMITED_MARKETCAP_A；不得拿当前值回填。
- 主力净流入：源同日main_net；主力净流入占比：main_net/A（无量纲）。120日接口早期缺数据保留NaN。
- 当日换手率：V/历史同日可流通A股本×100，单位百分数。5日累计换手：最近5有效记录turn之和。
- 20日波动率：std(r最近20)，样本ddof=1。
- 60日突破幅度：C/此前60有效记录最高C−1。
- 信号前一日涨跌幅：lag(r,1)。
- 信号前3日动量：C_{T−1}/C_{T−4}−1。
- 信号前10日量比：V_{T−1}/mean(V截至T−1的10记录)。
- 信号前5日均额对数：ln(1+mean(A截至T−1的5记录))，A单位元。
- 信号前20/60日涨停次数：截至T−1的20/60有效记录收盘涨停次数。
- 信号前20日高点距离：C_{T−1}/max(H截至T−1的20有效记录)−1。
- 信号日实体占振幅比：(C_T−O_T)/(H_T−L_T)。

以上共42因子，以factor_definitions.csv名字为唯一键。“突破幅度20”与“60日突破幅度”不得互换；“信号前”因子不能混入T值；“均线价格位置”的N在冻结实现中是120，不是60。
